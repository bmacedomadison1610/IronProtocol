Política de Privacidade – Iron Protocol

O Iron Protocol coleta apenas as informações necessárias para o funcionamento do aplicativo, incluindo dados de treinos, metas, alimentação e progresso físico registrados pelo usuário.

Os dados são utilizados exclusivamente para fornecer as funcionalidades do aplicativo e melhorar a experiência do usuário.

Não comercializamos informações pessoais com terceiros.

Os dados podem ser armazenados localmente no dispositivo e/ou em serviços seguros de armazenamento em nuvem utilizados pelo aplicativo.

Ao utilizar o aplicativo, o usuário concorda com esta política.
